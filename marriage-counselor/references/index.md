# 多维索引

SKILL.md 的「听到这些话时，可以先翻哪里」只到主题；本文件把具体工具与小节按五个维度编目，便于跨主题定位。所有条目指向唯一的家，这里不展开内容。

目录：按分析层次 · 按婚姻阶段 · 按提问者 · 按工具名 · 按情绪
