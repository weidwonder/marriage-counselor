# 积极沟通：把想法说成对方听得进的话

目录：抱怨 · 肯定法 · 让伴侣愿意做家务 · 吵架不伤感情 · 非暴力沟通 · 沟通的五个层次 · 可以试试的小练习

## 抱怨

抱怨是在讲"你不要的东西"，而不是"你要的东西"；越抱怨，对方越远，形成"越抱怨越不回家、越不回家越抱怨"的循环。

**抱怨的四种原因与回应**：

| 原因 | 识别 | 被抱怨时怎么回应 |
|------|------|-----------------|
| 需要没被满足 | 背后有一个具体需要（被安慰、被分担） | 找出那个需要；能满足就满足，满足不了也肯定其合理并商量 |
| 想引起关注 | 抱怨的都是可有可无的小事（物价、天气） | 直接给关注，并问清对方想要的"被关注"具体是什么 |
| 情绪堆积 | 小事引爆，旧账连连 | 找时间好好谈那件没处理完的旧事，让积压的情绪出来 |
| 推卸责任 | "都怪你/都怪我的出身"，给建议也不听 | 用提问引导看见自己能承担的部分："如果你有能力处理，会怎么做？""如果问题已经解决了，你觉得是发生了什么？" |

**替代抱怨的两件事**：

1. **直接说需要**：把"你就不能洗个碗吗？我忙了一整天"换成"我今晚很累，想歇会儿，你去洗碗好吗？"很多人觉得直接提要求别扭，于是先摆出自己的付出再暗示，结果听起来全是指责。
2. **用鼓励代替抱怨**：反复抱怨会让对方给自己贴上那个标签（"我就是乱扔袜子的人"），反而更这样做。一个方法用了一百次没用，第一百零一次换一种：对方没做好时不帮做、也不念叨；对方一旦朝期待的方向做了一点，立刻具体地真心表扬。抱怨是负强化，鼓励是正强化。

**想抱怨时**：停下来做十次深长呼吸 → 心里默念"他一定有我不知道的难处" → 手放胸口给自己关怀（"这是一个难受的时刻，每个人都会这样，愿我善待自己"）→ 情绪过去后再用对方能接受的方式说需要。

**被抱怨时**：先给一个宽容的微笑，自己有情绪先处理自己的 → 感受抱怨背后想说什么 → 按上表原因回应。

## 肯定法

越是老夫老妻越需要好听的话。"好看吗？""好看。""哪里好看？""哪都好看。"——有来有往却没有真正的回应，会被听成敷衍。

**三段论肯定法**：表达当下的感受 + 具体描述 + 前后对比。

- 伴侣试新衣服："哇，眼前一亮（感受）。这个颜色把你的肤色衬得特别亮（具体）。比上次那件更有精神（对比）。"
- 伴侣分享拿下大单："太厉害了，这可不是谁都拿得下的（感受）。那么多竞争对手，你是怎么胜出的？（具体，邀请继续讲）感觉你现在处理这种局面越来越从容了（对比）。"

**找不到可以肯定的地方时，按五个方向退而求其次**：

1. 肯定对方说过的话：找出一句你能认同的复述出来（心理学称"镜映"，人都希望被认同）。
2. 肯定对方的情绪：不认同做法，也认同感受（"你想被欣赏，这个感受我懂"）。
3. 肯定对方的动机："我知道你这么拼是为了这个家。"再接明确的需要："比起钱，我和孩子更需要你多陪陪我们。"
4. 从对方的角度肯定："我暂时还不理解，但你这么想一定有你的道理，能多说说吗？"
5. 承认还有新的可能："也许我误会了你的意思，这一点我们再聊聊。"

连这五个方向都找不到时，建议寻求婚姻咨询师帮助。

**"上帝心态"与"用户思维"**：有的人在家里默认"你是我的伴侣，就该满足我"；而在外面让伴侣感到舒服的人，往往在意"我说的话能不能让对方高兴"。来访者可以选择不这样沟通，但需要知道选择的后果；若希望和伴侣心灵相通，就需要敞开自己学习有效的表达。

## 让伴侣愿意做家务

不愿做家务常见两种原因：观念传统（"男主外"），或更常见的——做了反而挨骂，只尝到"越做越错"，于是干脆不做。目标是让对方体验到：做家务 → 伴侣开心 → 伴侣更爱我 → 我开心。

**正向循环话术**＝情绪价值 + 量化的具体付出 + 利益价值。
"今天好累，幸好有你在（情绪价值）。等会儿能不能花一个小时，我们一起把家收拾一下（量化付出）？弄完我给你按按肩（利益价值）。"

**积极反馈话术**＝表达需要 + 描述细节 + 夸奖 + 情绪。做完后热情地感谢，哪怕只做了一点、做得不够好：
"有你一起收拾我轻松多了（需要）。你把灶台边那些油渍都擦掉了（细节），厨房一下子亮了（夸奖），我要拍下来发给我妈看（情绪）。"
也可用于邀请伴侣参与育儿："晚上你来给孩子讲故事好吗？上次你学的那个怪兽声音，他到现在还在模仿，他可崇拜你了。"

收到心意时不要客套推辞（"买这个干吗"），热情的感谢才会让对方愿意继续付出。

## 吵架不伤感情

**四种伤感情的吵法**：

1. **不分场合**：把夫妻矛盾闹到单位、家族群、朋友圈。发泄一时痛快，常把对方彻底推走。
2. **翻旧账**：吵眼下的事却扯出多年前的"你没照顾好孩子"，等于否定对方的价值。
3. **上纲上线**：从具体小事升级到人格（"你就是个伪善的人"）。
4. **推卸责任**："孩子成绩差是你们家基因不好"。

**吵架不伤情四步**：

1. **表达情绪，但不情绪化地表达**："我现在非常生气，想自己静一会儿。"而不是挑对方最痛的地方说。
2. **澄清事实，确认差异点**：冷静后就事论事，让双方都说出各自的观点与来由。
3. **认同对方的需要和动机**：这是越吵越亲的关键。坚持孩子必须学某样东西的一方，可能在弥补自己童年被迫放弃的遗憾；坚持另一样的一方，可能怕孩子重复自己被欺负的经历。看见彼此借孩子在疗愈自己，坚持就会松动。
4. **抓住修复信号，经营情感账户**：平时往"情感账户"里多存爱与温暖，吵后用语言（"我们不吵了""我记住了"）、表达（拥抱、拍肩、聊感受、回忆往事）、行动（"出去吃饭吧""周末去看你爸妈"、做饭、小礼物）修复。

吵之前问自己两个问题：我要的是幸福还是对错？是要我赢，还是我们好？

**补充**（来源：约翰·戈特曼的研究）：最能预测关系恶化的四种互动是批评（攻击人格而非行为）、蔑视（嘲讽、翻白眼、居高临下）、防御（只顾辩解、反过来指责）、筑墙（沉默撤离、拒绝回应）；其中蔑视的破坏力最强。对应解药分别是用"我"开头说具体抱怨、平时表达欣赏、为自己那部分承担责任、情绪过载时说明暂停并约定回来的时间。与上面四种吵法可对照使用。

## 非暴力沟通

（来源：马歇尔·卢森堡《非暴力沟通》）亲密关系最需要的是不指责、不批评、不评判。四个要素：

1. **观察事实，不夹评判**：留意"你总是/你从来/你永远/我觉得你就是"后面跟的往往是评判。
   - 评判："你根本不想回家。" 事实："你这周有三天十一点后才到家。"
   - 评判："你心里只有你自己。" 事实："你盛饭时只盛了自己那碗。"
2. **表达感受，不是想法**："我觉得我不是个好妈妈"是评价；"孩子没考好，我很难过、失落"是感受。注意"被抛弃、被忽视、被利用、不受重视"这类词表达的是对别人的判断，不是感受；可替换为害怕、担心、孤单、委屈、失望、愤怒、灰心等。
3. **说出需要**：感受背后是什么需要——被关心、被陪伴、被尊重、整洁、安全。
4. **提出明确、可执行的请求**："以后对我好点"太抽象；"每天出门前抱我一下"可执行。"别把袜子扔沙发上"不如"把袜子放进洗衣篮"。

示例：伴侣醉酒深夜回家，与其说"早晚喝死在外面"，不如说："你这三天都过了十一点才回来，又喝了不少（事实）。我很担心你的身体，一个人在家也很孤单（感受）。医生说你得戒酒，你还这样喝，我是真的害怕（感受）。孩子去住校了，我需要你的陪伴，也需要你健健康康的（需要）。我知道应酬推不掉，我支持你的工作；我希望你以后十点前到家，这段时间按医生说的不喝酒，好吗？（理解 + 请求）"

四步不必一字不差地走完。核心是爱、懂得、心疼与回应，形式可以灵活。

## 沟通的五个层次

（源自约翰·鲍威尔的沟通层次模型，经林文采博士在华人圈推广）由浅到深：

| 层次 | 内容 | 夫妻中的样子 |
|------|------|-------------|
| 1 打招呼 | 寒暄 | "回来了？""吃了吗？"只剩这些，说明已很疏远；冷战中想破冰可从这里重新开始 |
| 2 讲事实 | 交换信息，不谈感受 | 家长会时间、周末去哪，像同事交接 |
| 3 谈想法 | 分享看法、邀请对方参与 | "孩子成绩下滑，你觉得要不要和他聊聊？"怕被质疑的人会退回前两层 |
| 4 谈感受 | 分享情绪 | "我最近很难过。"风险最大的一跃：若换来"你有什么好难过的"，以后就不再说 |
| 5 敞开心扉 | 袒露脆弱、隐私、缺点 | 相信"无论我是什么样子，对方都接纳我"；需要安全、接纳的氛围 |

很多"天天在说话却不亲密"的夫妻停在第二层。练习方向：先在第三层多问对方的看法；对方说出感受时，用共情接住（见 empathy.md「共情沟通两步」），让对方敢继续往深处走。

## 可以试试的小练习

- 观察自己这周最常抱怨什么，各对应上表哪种原因，把其中一句改写成直接的需要。
- 每天用三段论肯定法真心肯定伴侣一次。
- 用正向循环话术邀请伴侣做一件家务，做完用积极反馈话术感谢，记录对方下次的主动程度。
- 回想上一次吵架用了四种伤人吵法中的哪一种，按四步法写下当时可以怎么说。
- 选一件你最不喜欢伴侣做的事，用"事实 + 感受 + 需要 + 请求"写成一段话，读给对方听。
- 判断你们平时停在第几层沟通，这周试着往上走一层。
