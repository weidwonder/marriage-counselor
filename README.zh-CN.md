# marriage-counselor 婚姻咨询师

**简体中文** · [English](README.md)

一个 Agent Skill：让 AI 以婚姻咨询师的身份，陪已婚、即将结婚或长期同居的伴侣聊聊关系里的困惑。它先接住情绪、留意安全风险，再从两性差异、依恋与原生家庭、情绪、共情、沟通和婚姻危机几个层面找到问题的根源，最后给出能照着说的话和回家能试的小练习。

## 适合聊什么

- 冷战、吵架、"他根本不懂我""她天天抱怨"
- 婆媳矛盾、为钱争吵、无性婚姻、七年之痒
- 发现出轨后不知去留、想离婚又舍不得
- 关系还不错，想让它更好

已婚、快要结婚、长期同居或处在稳定伴侣关系里的人都适用，同性伴侣也一样。

## 不做什么

- 恋爱追求、挽回前任、亲子教育
- 离婚财产、抚养权等法律问题（会建议咨询律师）
- 精神疾病的诊断与用药（会建议就医）
- 危机干预：遇到自伤自杀、家暴或性暴力，只做第一轮安全回应并给出求助热线，不替代专业危机干预和精神科诊疗

离不离婚、原不原谅，始终由来访者自己决定，技能不替人拿主意。

## 对话是什么样的

咨询的流程、对安全的留意、理论和术语，都只在 AI 心里进行。来访者感受到的是一个温和、懂行的人在聊天：口语、短段落，一次只问一两个问题；猜测用"我在想，会不会……"轻轻提出，建议说成"要不要试试……"。

> **来访者**：结婚八年了，每次吵完他倒头就睡，我一个人哭到半夜。我是不是嫁错人了？
>
> **咨询师**：吵完架，他那边已经睡着了，你一个人醒着把那些话在心里来回过，那种被留在原地的感觉真的很孤单。"是不是嫁错人"这个念头，是这一次突然冒出来的，还是已经在心里很久了？

一次完整的咨询大致会经过：接住情绪 → 理清事情 → 找到根源 → 给方法 → 小练习与回访；每一轮都会先在心里留意安全信号。节奏由来访者决定，只想倾诉时就一直陪着听。

回复语言跟随来访者，简体、繁体、英文或其他语言都可以。

## 安装

技能本身是纯 Markdown，没有脚本，也不需要安装依赖。把仓库里的 `marriage-counselor/` 目录复制到 Agent 的 skills 目录即可，以 Claude Code 为例：

```bash
git clone https://github.com/weidwonder/marriage-counselor.git
cp -r marriage-counselor/marriage-counselor ~/.claude/skills/
```

只想在某个项目里用，就复制到该项目的 `.claude/skills/`。

## 使用

不需要特别的命令，直接倾诉就会触发，例如：

- "我老公一吵架就不理我"
- "婆婆总插手我们带孩子，我老公只会让我忍"
- "发现老婆出轨了，要不要离婚？"
- "my wife and I keep fighting"

## 方法来源

方法按七个主题组织：两性差异、允许差异、情绪、共情、沟通、婚姻危机、成长与原生家庭。资料中引用的理论包括：盖瑞·查普曼的"爱的五种语言"、约翰·戈特曼的爱情地图与关系研究、马歇尔·卢森堡的非暴力沟通、依恋理论、阿尔伯特·埃利斯的情绪 ABC、莱斯特·卢博斯基的 CCRT、卡罗尔·德韦克的成长型思维、库伯勒-罗丝的五阶段模型、约翰·鲍威尔的沟通层次等，出处都在相应条目旁注明。资料中标注「补充」的内容，来自通行的心理学研究。

男女差异只当作常见倾向使用；证据薄弱的通俗说法（例如"细胞七年代谢一次所以有七年之痒"）不会被当作科学事实讲给来访者，校正规则见 `references/safety.md`「常见说法的使用校正」。

## 请注意

这是 AI 陪伴，不是持证心理咨询师的诊疗，也不能替代医生、律师或危机干预机构。如果你或身边的人正处在危险中，请立即拨打当地的紧急电话或心理援助热线。
